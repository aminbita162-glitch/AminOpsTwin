ELEVATED STRATEGIC IDEAS (binding for this stage)
Idea S1 — Evidence Claim Registry + Independent Verify CLI
  Every claim in README and reports receives a claim-id. Each claim-id maps to a signed evidence-pack hash. A standalone CLI tool (aminopstwin-verify) must be able to verify any claim without running the full system.
Idea S2 — Deterministic Prior Pack from Public Aggregate Data
  Extract aggregate distributions (phase duration, site count, enrollment rates) from ClinicalTrials.gov / AACT public aggregates. Package them as a versioned, signed Capability Pack that the Twin can load as priors. No private data.
Idea S3 — Shadow-Mode Ingestion Gateway + Data Contract v1
  A dedicated ingestion path that accepts only weekly aggregate CSV/JSON files under a strict Data Contract. Enforces schema, k-min cell suppression, and produces a hashed receipt. Output is limited to aggregate forecast-vs-actual comparison.
Idea S4 — State Hash Cross-Platform Oracle
  A fixed suite of determinism tests whose final state hashes must be identical on x86_64 and ARM64 and across two Python 3.12 patch versions. The oracle runs in CI and fails the build on mismatch.
Idea S5 — Owner Key Rotation & Hard-Stop Co-Signature Protocol
  A minimal protocol for rotating the owner signing key and allowing an optional co-signature on Hard-Stop reports. Reduces single-person bus factor without requiring full Shamir sharing in this stage.

P12 — CORE DETERMINISM AND SAFETY HARDENING
----------------------------------------------------------------------
Entry: P11 verified and owner has instructed P12.
Responsible: implementing agent.
Required (exact deliverables):
  1. Raw JSON ingestion at API edge (Idea support for S3):
     - Add a FastAPI dependency that reads request.body() as bytes.
     - Parse with json.loads(object_pairs_hook=..., parse_float=reject, parse_constant=reject).
     - Reject duplicate keys, floats, NaN, Infinity with exact reason codes.
     - Place the function in src/aminopstwin/gateway/raw_json.py.
  2. Two IdFactory implementations:
     - DeterministicIdFactory: HMAC-SHA256(seed, domain||counter) truncated and formatted as UUID.
     - EntropyIdFactory: secrets.token_bytes only at the runtime edge.
     - step_id = H(workflow_id, step_no, attempt) for crash-safe retries.
     - Tests must prove no duplicate or orphan IDs after simulated crash.
  3. Close TOCTOU for policy_epoch:
     - In the commit transaction use:
       UPDATE steps SET state='COMMITTED', version=version+1
       WHERE id=:id AND version=:v AND :epoch = (SELECT current_epoch FROM policy_state FOR SHARE);
     - Zero rows → retry or DENY.
  4. Explicit StateFacts for Gateway:
     - Executor builds an immutable StateFacts snapshot (idempotency record, budget balance, tenant link, policy epoch/hash) and passes it to the pure Gateway function.
     - DecisionRecord includes hash(StateFacts).
  5. Integer-oriented simulation time and dedicated PRNG:
     - Simulation clock becomes integer ticks (milliminutes).
     - Named PRNG streams (PCG32 or xoshiro256**) keyed by H(seed, entity_name).
     - Ban math.* floating-point operations on the hashed state path.
  6. State Hash Cross-Platform Oracle (Idea S4):
     - Add tests/twin/test_cross_platform_oracle.py.
     - CI matrix must run on x86_64 and ARM64; final state hash must match exactly.
